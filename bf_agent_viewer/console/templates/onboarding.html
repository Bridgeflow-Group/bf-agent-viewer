No agents registered yet

BF Agent Viewer doesn't show anything until at least one agent identity is registered and starts calling tools through the gateway.

Register your first agent

From the command line:

bf-agent-viewer register --db bf-agent-viewer.db --org <org-id> \
  --agent-id my-agent --name "My Agent" --owner <human-id> \
  --scope tool_a tool_b

This prints an API token and the header name to send it with (X-BF-Agent-Token). Point your agent's MCP client at the gateway with that header set, and activity will start showing up here.
